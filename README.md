# 🚀 软件项目管理 AI 知识库问答助手 (RAG)

## 📖 项目简介
本项目是一个基于 **RAG (检索增强生成)** 架构与大语言模型（LLM）构建的垂直领域知识问答系统。旨在解决传统大模型在特定专业知识回答中容易产生的“幻觉（胡编乱造）”问题，为用户提供精准、有据可查的解答。

👉 **[点击这里，立即在线体验 Demo](https://www.coze.cn/store/agent/7697255819569709065?bot_id=true)** 👈

## ✨ 核心功能
- **精准知识问答**：严格基于上传的《软件项目管理核心知识精要》文档进行回答，不瞎编。
- **源头引用**：每次回答后，系统会自动附带原文出处（如：依据第四章内容），提升回答可信度。
- **零代码搭建**：基于 Coze 平台，实现快速落地验证。

## 🛠️ 技术栈与架构
- **大模型 (LLM)**：豆包 2.0
- **核心架构**：RAG (Retrieval-Augmented Generation)
- **开发平台**：扣子 (Coze.cn)
- **关键技术**：Prompt Engineering、知识库切片与向量化、深度思考参数调优

## 🔧 开发踩坑与性能优化记录 (核心亮点)
在项目搭建与调优过程中，遇到了以下技术挑战并成功解决：

1. **大文件解析失败**：初期上传 89.6MB 的超大 PDF 导致解析超时。后通过预处理提取核心文本，转为轻量级文件，大幅提升上传和解析速度。
2. **大模型“思维链泄漏”**：模型出现过度思考（耗时 35.9s，输出 1900+ Tokens 的内心独白）。
   - **解决方案**：通过优化 Prompt，增加“绝对禁止输出内心思考过程”的强约束。
   - **优化结果**：响应时间从 **35.9秒 骤降至 2.5秒**。
3. **参数冲突报错**：关闭“深度思考”模式时触发底层参数冲突。
   - **解决方案**：调整模型推理强度参数，并切换至响应更快的轻量化模型（豆包 Lite）。
   - **最终效果**：实现 2.0 秒内的极速、纯净、准确回复。
